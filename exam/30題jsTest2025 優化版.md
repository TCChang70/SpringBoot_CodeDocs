### 1. 下列哪個方法可以用來在JavaScript中建立迴圈並列印陣列的每個元素？

```javascript
var arr = [1, 2, 3, 4, 5];
// 填入程式碼
{
    console.log(arr[i]);
}
```

- A. `arr.print();`
- B. `arr.forEach();`
- C. `for (var i = 0; i < arr.length; i++) { console.log(arr[i]); }`
- D. `arr.each();`

**答案：C**

**說明：** JavaScript 陣列沒有 `print()` 或 `each()` 方法。`forEach()` 是陣列方法，但需要傳入回呼函數，不是直接呼叫。選項 C 使用傳統 for 迴圈，是最基本的陣列遍歷方式。

## 常用方法速查表

### JavaScript 陣列
| 方法 | 說明 | 範例 |
|-----|------|------|
| `push()` | 末尾添加元素 | `arr.push(1)` |
| `pop()` | 移除末尾元素 | `arr.pop()` |
| `shift()` | 移除開頭元素 | `arr.shift()` |
| `unshift()` | 開頭添加元素 | `arr.unshift(1)` |
| `splice()` | 任意位置增刪 | `arr.splice(2, 1)` |
| `concat()` | 合併陣列 | `arr1.concat(arr2)` |
| `includes()` | 檢查是否包含 | `arr.includes(3)` |
| `indexOf()` | 查找元素位置 | `arr.indexOf(3)` |
| `reverse()` | 反轉陣列 | `arr.reverse()` |
| `sort()` | 排序陣列 | `arr.sort()` |
| `join()` | 連接為字串 | `arr.join(", ")` |
| `toString()` | 轉換為字串 | `arr.toString()` |

### jQuery 常用方法
| 方法 | 說明 | 範例 |
|-----|------|------|
| `attr()` | 獲取/設置屬性 | `$(el).attr("id")` |
| `removeAttr()` | 移除屬性 | `$(el).removeAttr("id")` |
| `val()` | 獲取/設置表單值 | `$(el).val()` |
| `text()` | 獲取/設置文字 | `$(el).text()` |
| `html()` | 獲取/設置HTML | `$(el).html()` |
| `css()` | 獲取/設置CSS | `$(el).css("color")` |
| `addClass()` | 新增class | `$(el).addClass("active")` |
| `removeClass()` | 移除class | `$(el).removeClass("active")` |
| `toggleClass()` | 切換class | `$(el).toggleClass("active")` |
| `hasClass()` | 檢查class | `$(el).hasClass("active")` |
| `append()` | 內部末尾插入 | `$(el).append("<p>")` |
| `prepend()` | 內部開頭插入 | `$(el).prepend("<p>")` |
| `before()` | 外部前面插入 | `$(el).before("<p>")` |
| `after()` | 外部後面插入 | `$(el).after("<p>")` |
| `hide()` | 隱藏元素 | `$(el).hide()` |
| `show()` | 顯示元素 | `$(el).show()` |
| `on()` | 綁定事件 | `$(el).on("click", fn)` |
| `off()` | 移除事件 | `$(el).off("click")` |
| `$.get()` | GET請求 | `$.get(url, fn)` |
| `$.post()` | POST請求 | `$.post(url, data, fn)` |
| `$.ajax()` | AJAX請求 | `$.ajax({})` |
