# 1. 系統架構與學習地圖

## 1.1 這套系統在做什麼？

**庫存監控模組**解決一個實際商業問題：**哪個產品快賣完了，需要補貨？**

- `products` 表已有 110 筆真實產品資料（來自 classicmodels 範例資料庫）
- 我們**新增一張 `stock_thresholds`（安全水位）表**，記錄「庫存低於多少要警示」
- 提供三大功能畫面：
  - **儀表板**：一眼看出各產品線庫存狀態、緊急補貨清單
  - **產品管理**：搜尋、篩選、看毛利率
  - **低庫存警示**：列出庫存過低產品，可設定安全水位

## 1.2 整體架構圖

```
┌─────────────────────────────────────────────────────┐
│  前端（三選一）                                    │
│  ├── Angular 17   (port 4200)                    │
│  ├── React 18     (port 3000)                    │
│  └── Vite + React (port 5173)                    │
└──────────────────────┬──────────────────────────────┘
                       │ HTTP (JSON)
                       ▼
┌─────────────────────────────────────────────────────┐
│  後端 Spring Boot (port 8080)                      │
│  Controller → Service → Repository → JPA → MySQL   │
└─────────────────────────────────────────────────────┘
```

## 1.3 為什麼要分層？

| 層 | 職責 | 你想像成 |
|----|------|---------|
| Controller | 接收 HTTP 請求、回傳結果 | 餐廳**服務生** |
| Service | 業務邏輯、交易管理 | **主廚** |
| Repository | 跟資料庫打交道 | **食材倉庫管理員** |
| Entity | 代表一張資料表 | **菜單上的一道菜** |

**核心原則**：高層依賴低層，低層不依賴高層。這樣單向依賴讓程式**容易理解、容易測試、容易替換**。

## 1.4 學習地圖

```
Step 1  建資料庫          → products + stock_thresholds
Step 2  後端骨架          → pom.xml + application.properties + 啟動類
Step 3  寫 Query          → Entity + Repository（這是最有成就感的一步）
Step 4  包裝業務邏輯      → DTO + Service
Step 5  開 API 給前端      → Controller + 例外處理 + CORS
Step 6  前端畫面          → Angular / React / Vite 三選一
Step 7  串接驗證          → 讓前端成功呼叫後端
```

| Node.js | 18+ | 跑前端工具鏈 |
| IDE | IntelliJ / VS Code | 寫程式 |

## 2.2 建立資料庫

```sql
-- 建立 classicmodels 資料庫（若尚未存在）
CREATE DATABASE IF NOT EXISTS classicmodels
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_unicode_ci;

USE classicmodels;

-- 建立安全水位表
CREATE TABLE stock_thresholds (
    id               INT AUTO_INCREMENT PRIMARY KEY,
    product_code     VARCHAR(15) NOT NULL UNIQUE,
    min_quantity     INT NOT NULL DEFAULT 200,
    reorder_quantity INT NOT NULL DEFAULT 500,
    updated_at       DATETIME DEFAULT CURRENT_TIMESTAMP
                       ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT fk_threshold_product
        FOREIGN KEY (product_code) REFERENCES products(productCode)
        ON DELETE CASCADE
);
```

### 概念：外鍵（FOREIGN KEY）+ UNIQUE

- `product_code` 設 **UNIQUE**：一支產品**只能有一筆**安全水位 → 一對一關係
- `ON DELETE CASCADE`：產品刪了，它的安全水位自動刪 → 避免孤兒資料

### 動手做後驗證

```sql
-- 看看目前庫存最低的產品（低庫存警示的目標對象）
SELECT productCode, productName, quantityInStock
FROM products
ORDER BY quantityInStock ASC
LIMIT 5;
```

## 3.2 設定檔 application.properties

```properties
# ===== 伺服器 =====
server.port=8080

# ===== MySQL 連線 =====
spring.datasource.url=jdbc:mysql://localhost:3306/classicmodels?useSSL=false&serverTimezone=Asia/Taipei&characterEncoding=UTF-8
spring.datasource.username=root
spring.datasource.password=你的密碼
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

# ===== JPA / Hibernate =====
spring.jpa.database-platform=org.hibernate.dialect.MySQLDialect
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=false
```

### 逐項解釋

| 設定 | 作用 |
|------|------|
| characterEncoding=UTF-8 | 避免中文亂碼 |
| serverTimezone=Asia/Taipei | JPA 要用到日期時間需要正確時區 |
| ddl-auto=update | Boot 會**自動建立/更新表**（這次練習用它最省事） |
| show-sql=false | 不印 SQL（除錯時可改 true） |

> ⚠️ **ddl-auto 的 4 個值**（依環境慎選）：
> - `update`：開機自動新增欄/表（**練習用**）
> - `none`：完全不管（**正式用**）
> - `create-drop`：關機刪表（**不要用在產品上**）
> - `validate`：只驗證對不對（**嚴格用**）

# 4. 資料庫設計概念

## 4.1 兩張表的關係

```
products               stock_thresholds
─────────              ─────────────────
productCode (PK)  ←──  product_code (FK, UNIQUE)
productName                min_quantity
quantityInStock           reorder_quantity
buyPrice / MSRP           updated_at
```

### 這是什麼關係？

**一對一（1:1）**：一支產品**最多**一個安全水位。所以 `product_code` 設 `UNIQUE`。

### 為什麼不用每支產品都預設一筆？

- 大部分產品庫存充足，不需要安全水位
- 用**預設值兜底**（min=200）既簡單又省空間

## 4.2 需要注意的陷阱

> ⚠️ **別把 `stock_thresholds` 的欄位直接加進 `products` 表**
> - 會污染既有範例資料表
> - 會讓「產品」跟「水位設定」耦合成一張寬表，日後難維護
> - 應使用**獨立表 + 外鍵**，職責分離

# 5. Entity：資料與程式的橋樑

## 5.1 概念：什麼是 Entity？

Entity 是一個 **Java 類別對應一張資料表**。JPA 靠它把資料列的欄位值，裝進 Java 物件的屬性，方便你在程式裡操作。

| JPA 概念 | 對應資料庫 | 作用 |
|----------|-----------|------|
| `@Entity` | 表格 | 標記這是資料表對應類別 |
| `@Table(name)` | 表名 | 指定對應哪張表 |
| `@Id` + `@Column` | 主鍵、欄位 | 對應資料表欄位 |

> 💡 **為什麼要用 Entity 而不是直接寫 SQL？**
> JPA 幫你處理「Java 物件 ↔ 資料列」的轉換，你專注在「資料 + 邏輯」，SQL 交給 JPA 產生。

## 5.2 動手做：Product Entity

```java
// src/main/java/com/classicmodels/inventory/model/Product.java
package com.classicmodels.inventory.model;

import jakarta.persistence.*;

@Entity
@Table(name = "products")
public class Product {

    @Id
    @Column(name = "productCode", length = 15)
    private String productCode;

    @Column(name = "productName", nullable = false, length = 70)
    private String productName;

    @Column(name = "productLine", nullable = false, length = 50)
    private String productLine;

    @Column(name = "productScale", nullable = false, length = 10)
    private String productScale;

    @Column(name = "productVendor", nullable = false, length = 50)
    private String productVendor;

    @Column(name = "productDescription", nullable = false, columnDefinition = "TEXT")
    private String productDescription;

    @Column(name = "quantityInStock", nullable = false)
    private int quantityInStock;

    @Column(name = "buyPrice", nullable = false)
    private double buyPrice;

    @Column(name = "MSRP", nullable = false)
    private double msrp;

    // 為了節省篇幅，Getter/Setter 請自行補齊（IDE 可自動產生）
    // 例如：
    // public String getProductCode() { return productCode; }
    // public void setProductCode(String productCode) { this.productCode = productCode; }
}
```

### @Column 屬性說明

| 屬性 | 作用 | 重點 |
|------|------|------|
| `nullable = false` | 對應欄位非空 | 寫入時若 null 會錯 |
| `length = 15` | 字串長度上限 | 可做為驗證輔助 |
| `columnDefinition = "TEXT"` | 指定 SQL 型別 | 長的描述欄位用 TEXT |

## 5.3 動手做：StockThreshold Entity

```java
// src/main/java/com/classicmodels/inventory/model/StockThreshold.java
package com.classicmodels.inventory.model;

import jakarta.persistence.*;
import java.time.LocalDateTime;

@Entity
@Table(name = "stock_thresholds")
public class StockThreshold {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Integer id;

    @Column(name = "product_code", nullable = false, unique = true, length = 15)
    private String productCode;

    @Column(name = "min_quantity", nullable = false)
    private int minQuantity = 200;

    @Column(name = "reorder_quantity", nullable = false)
    private int reorderQuantity = 500;

    @Column(name = "updated_at")
    private LocalDateTime updatedAt;

    @PrePersist
    @PreUpdate
    public void onUpdate() {
        this.updatedAt = LocalDateTime.now();
    }

    // Getter/Setter 請自行補齊
}
```

### 幾個關鍵點

| 程式 | 作用 |
|------|------|
| `@GeneratedValue(strategy = IDENTITY)` | 主鍵交給資料庫自增（auto_increment） |
| `minQuantity = 200` | **Java 端預設值**，與 SQL 預設一致，雙保險 |
| `@PrePersist` / `@PreUpdate` | 存檔前自動更新時間戳，免手動呼叫 |

> ⚠️ **為什麼資料庫跟 Java 都要設預設值 200？**
> 當你用「程式新增紀錄」時，用的是 Java 預設；若有人直接寫 SQL，用的是資料庫預設。兩者一致才不會行為不同。

# 6. Repository：JPA 查詢魔法

## 6.1 概念：方法命名查詢（Derived Query）

Spring Data JPA 有一個神奇機制：**只要照命名規則寫方法名字，它自動產生 SQL**。

```java
public interface ProductRepository extends JpaRepository<Product, String> {

    // 方法名「findByProductLine」→ 自動轉成：
    // SELECT p FROM products p WHERE p.productLine = ?
    List<Product> findByProductLine(String productLine);
}
```

### 命名規則拆解

```
find  By  ProductLine
 │    │       │
 │    │       └── 屬性名（Product_PK的屬性 productLine）
 │    └─ 條件關鍵字
 └─ 動作（查詢）
```

## 6.2 動手做：ProductRepository

```java
// src/main/java/com/classicmodels/inventory/repository/ProductRepository.java
package com.classicmodels.inventory.repository;

import com.classicmodels.inventory.model.Product;
import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.data.jpa.repository.Query;
import org.springframework.data.repository.query.Param;

import java.util.List;

public interface ProductRepository extends JpaRepository<Product, String> {

    // 方法命名查詢：依產品線
    List<Product> findByProductLine(String productLine);

    // 方法命名查詢：依供應商
    List<Product> findByProductVendor(String productVendor);

    // @Query + JPQL：關鍵字搜尋（名稱或描述含關鍵字）
    @Query("SELECT p FROM Product p WHERE " +
           "LOWER(p.productName) LIKE LOWER(CONCAT('%', :keyword, '%')) OR " +
           "LOWER(p.productDescription) LIKE LOWER(CONCAT('%', :keyword, '%'))")
    List<Product> searchByKeyword(@Param("keyword") String keyword);

    // @Query 子查詢：低庫存（低於安全水位，無水位用 200 兜底）
    @Query("SELECT p FROM Product p WHERE p.quantityInStock < " +
           "(SELECT COALESCE(st.minQuantity, 200) FROM StockThreshold st " +
           " WHERE st.productCode = p.productCode)")
    List<Product> findLowStockProducts();

    // @Query 聚合 + GROUP BY：Dashboard 統計
    @Query("SELECT p.productLine, SUM(p.quantityInStock), COUNT(p), MIN(p.quantityInStock) " +
           "FROM Product p GROUP BY p.productLine ORDER BY SUM(p.quantityInStock) DESC")
    List<Object[]> getStockSummaryByProductLine();

    // DISTINCT：下拉選單選項
    @Query("SELECT DISTINCT p.productLine FROM Product p ORDER BY p.productLine")
    List<String> findDistinctProductLines();

    @Query("SELECT DISTINCT p.productVendor FROM Product p ORDER BY p.productVendor")
    List<String> findDistinctVendors();
}
```

## 6.3 重要：JpaRepository 內建方法

不需要自己寫，繼承就有：

| 方法 | 作用 |
|------|------|
| `findAll()` | 查全部 |
| `findById(id)` | 依主鍵查（回傳 `Optional`） |
| `save(entity)` | 新增或更新（有主鍵＝更新） |
| `delete(entity)` / `deleteById(id)` | 刪除 |
| `existsById(id)` | 判斷是否存在 |

## 6.4 JPQL 補充說明

JPQL 用的**不是資料表名/欄位名**，而是 **Entity 類別名/屬性名**：
- 資料表 `products` → Entity `Product`
- 欄位 `quantityInStock` → 屬性 `quantityInStock`

參數用 `:名稱` 宣告，再用 `@Param("名稱")` 對應。

> 💡 **COALESCE(st.minQuantity, 200)** = SQL 的「如果 null 就用 200」。這讓「沒設定水位的產品」也有可比對基準。

# 7. DTO：控制回傳內容

## 7.1 概念：為什麼要 DTO？

把 Entity 直接丟給前端**有兩個問題**：
1. **洩漏內部細節**：Entity 可能含不想曝光的欄位
2. **胖 JSON**：Entity 很多欄位，前端不一定全要

**DTO（Data Transfer Object）** 是你定義的「傳輸用」資料形狀，控制**API 收進什麼、回傳什麼**。

## 7.2 動手做：ProductDTO

```java
// src/main/java/com/classicmodels/inventory/dto/ProductDTO.java
package com.classicmodels.inventory.dto;

import jakarta.validation.constraints.*;

public class ProductDTO {

    @NotBlank(message = "產品代碼不可空白")
    @Size(max = 15)
    private String productCode;

    @NotBlank(message = "產品名稱不可空白")
    @Size(max = 70)
    private String productName;

    @NotBlank
    private String productLine;

    @NotBlank
    private String productScale;

    @NotBlank
    private String productVendor;

    @NotBlank
    private String productDescription;

    @Min(value = 0, message = "庫存不可為負")
    private int quantityInStock;

    @DecimalMin(value = "0.0", message = "進價不可為負")
    private double buyPrice;

    @DecimalMin(value = "0.0", message = "售價不可為負")
    private double msrp;

    // Getter/Setter 請自行補齊
}
```

### 驗證註解：用來擋掉壞資料

| 註解 | 用途 |
|------|------|
| `@NotBlank` | 不可空白（null、""、全部空格都不行） |
| `@Size(max=)` | 長度上限 |
| `@Min` / `@DecimalMin` | 數值下限 |

> ⚠️ **這些註解要在 Controller 加 `@Valid` 才會生效**（第九章）。

## 7.3 動手做：ApiResponse（統一包裝）

```java

        res.success = true;

    public static <T> ApiResponse<T> ok(String message, T data) {
        ApiResponse<T> res = new ApiResponse<>();

        res.message = message;
        res.data = data;
        return res;
    }

    // Getter/Setter 請自行補齊
}
```

# 8. Service：業務邏輯核心

## 8.1 概念

Service 是**應用程式的核心腦**，負責：
- 呼叫 Repository 拿資料
- 套用業務規則（例如：找不到就想拋例外）
- 管理**交易（@Transactional）**
- 把 DTO 轉成 Entity、Entity 轉回 (給 Controller 用)

## 8.2 動手做：ProductService

```java
// src/main/java/com/classicmodels/inventory/service/ProductService.java
package com.classicmodels.inventory.service;

import com.classicmodels.inventory.dto.ProductDTO;
import com.classicmodels.inventory.exception.ResourceNotFoundException;
import com.classicmodels.inventory.model.Product;
import com.classicmodels.inventory.repository.ProductRepository;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.List;

@Service
public class ProductService {

    private final ProductRepository productRepo;

    public ProductService(ProductRepository productRepo) {
        this.productRepo = productRepo;
    }

    // ── 查詢（readOnly 交易：讀取專用，效能較好）──
    @Transactional(readOnly = true)
    public List<Product> findAll() {
        return productRepo.findAll();
    }

    @Transactional(readOnly = true)
    public List<Product> findByProductLine(String productLine) {
        return productRepo.findByProductLine(productLine);
    }

    @Transactional(readOnly = true)
    public List<Product> findByVendor(String vendor) {
        return productRepo.findByProductVendor(vendor);
    }

    @Transactional(readOnly = true)
    public List<Product> search(String keyword) {
        return productRepo.searchByKeyword(keyword);
    }

    @Transactional(readOnly = true)
    public List<Product> findLowStock() {
        return productRepo.findLowStockProducts();
    }

    @Transactional(readOnly = true)
    public Product findById(String productCode) {
        return productRepo.findById(productCode)
                .orElseThrow(() -> new ResourceNotFoundException(
                        "Product not found: " + productCode));
    }

    // ── 寫入（會真的動資料）──
    @Transactional
    public Product create(ProductDTO dto) {
        if (productRepo.existsById(dto.getProductCode())) {
            throw new IllegalArgumentException(
                    "Product code already exists: " + dto.getProductCode());
        }
        Product p = mapToEntity(dto);
        return productRepo.save(p);
    }

    @Transactional
    public Product update(String productCode, ProductDTO dto) {
        Product existing = findById(productCode);          // 不存在 → 拋 404
        existing.setProductName(dto.getProductName());
        existing.setProductLine(dto.getProductLine());
        existing.setProductScale(dto.getProductScale());
        existing.setProductVendor(dto.getProductVendor());
        existing.setProductDescription(dto.getProductDescription());
        existing.setQuantityInStock(dto.getQuantityInStock());
        existing.setBuyPrice(dto.getBuyPrice());
        existing.setMsrp(dto.getMsrp());
        return productRepo.save(existing);
    }

    @Transactional
    public void delete(String productCode) {
        Product existing = findById(productCode);
        productRepo.delete(existing);
    }

    // ── 私有工具：DTO → Entity ──
    private Product mapToEntity(ProductDTO dto) {
        Product p = new Product();
        p.setProductCode(dto.getProductCode());
        p.setProductName(dto.getProductName());
        p.setProductLine(dto.getProductLine());
        p.setProductScale(dto.getProductScale());
        p.setProductVendor(dto.getProductVendor());
        p.setProductDescription(dto.getProductDescription());
        p.setQuantityInStock(dto.getQuantityInStock());
        p.setBuyPrice(dto.getBuyPrice());
        p.setMsrp(dto.getMsrp());
        return p;
    }
}
```

```java
// src/main/java/com/classicmodels/inventory/service/StockThresholdService.java
package com.classicmodels.inventory.service;

import com.classicmodels.inventory.exception.ResourceNotFoundException;
import com.classicmodels.inventory.model.StockThreshold;
import com.classicmodels.inventory.repository.ProductRepository;
import com.classicmodels.inventory.repository.StockThresholdRepository;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
public class StockThresholdService {

    private final StockThresholdRepository thresholdRepo;
    private final ProductRepository        productRepo;

    public StockThresholdService(StockThresholdRepository thresholdRepo,
                               ProductRepository productRepo) {
        this.thresholdRepo = thresholdRepo;
        this.productRepo   = productRepo;
    }

    @Transactional(readOnly = true)
    public StockThreshold findByProductCode(String productCode) {
        return thresholdRepo.findByProductCode(productCode)
                .orElseThrow(() -> new ResourceNotFoundException(
                        "Threshold not found for product: " + productCode));
    }

    // Upsert = Update OR Insert（存在更新、不存在新增）
    @Transactional
    public StockThreshold upsert(String productCode, int minQty, int reorderQty) {
        if (productRepo.existsById(productCode) == false) {
            throw new ResourceNotFoundException("Product not found: " + productCode);
        }
        if (minQty <= 0 || reorderQty <= 0) {
            throw new IllegalArgumentException("Quantity values must be greater than 0");
        }

        StockThreshold t = thresholdRepo.findByProductCode(productCode)
                .orElse(new StockThreshold());
        t.setProductCode(productCode);
        t.setMinQuantity(minQty);
        t.setReorderQuantity(reorderQty);
        return thresholdRepo.save(t);
    }
}
```

## 8.4 摘要

| Service 動作 | 交易 | 用途 |
|-------------|------|------|
| `findAll / findBy / search` | readOnly | 讀取 |
| `create / update / delete / upsert` | 一般 | 寫入 |

> 💡 `@Transactional` 只包**同一個 Bean 的方法**；Controller 呼叫 Service 方法時會包進交易，多個 Repository 操作失敗時**一起回滾**。

# 9. Controller：對外 API 入口

## 9.1 概念

Controller 是**前端眼中唯一的後端**。它負責：
- 用 `@RequestMapping("/api/products")` 訂出 **REST 端點路徑**
- 用 `@GetMapping` / `@PostMapping` 等註解對應 **HTTP 方法**
- 呼叫 Service，包裝成 `ApiResponse` 回傳

### RESTful 重點

| HTTP 方法 | 意思 | 我們的端點 |
|-----------|------|-----------|
| GET | 讀取 | `/api/products` |
| GET | 讀取單筆 | `/api/products/{code}` |
| POST | 新增 | `/api/products` |
| PUT | 更新 | `/api/products/{code}` |
| DELETE | 刪除 | `/api/products/{code}` |

## 9.2 動手做：ProductController

```java
// src/main/java/com/classicmodels/inventory/controller/ProductController.java
package com.classicmodels.inventory.controller;

import com.classicmodels.inventory.dto.ApiResponse;
import com.classicmodels.inventory.dto.ProductDTO;
import com.classicmodels.inventory.service.ProductService;
import jakarta.validation.Valid;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

import java.util.List;

@RestController
@RequestMapping("/api/products")
public class ProductController {

    private final ProductService productService;

    public ProductController(ProductService productService) {
        this.productService = productService;
    }

    // GET /api/products?productLine=&vendor=&keyword=
    @GetMapping
    public ResponseEntity<ApiResponse<Object>> getAll(
            @RequestParam(required = false) String productLine,
            @RequestParam(required = false) String vendor,
            @RequestParam(required = false) String keyword) {

        Object result;
        if (keyword != null && !keyword.isBlank()) {
            result = productService.search(keyword);
        } else if (productLine != null && !productLine.isBlank()) {
            result = productService.findByProductLine(productLine);
        } else if (vendor != null && !vendor.isBlank()) {
            result = productService.findByVendor(vendor);
        } else {
            result = productService.findAll();
        }
        return ResponseEntity.ok(ApiResponse.ok(result));
    }

    // GET /api/products/{productCode}
    @GetMapping("/{productCode}")
    public ResponseEntity<ApiResponse<Object>> getById(@PathVariable String productCode) {
        return ResponseEntity.ok(ApiResponse.ok(productService.findById(productCode)));
    }

    // GET /api/products/low-stock
    @GetMapping("/low-stock")
    public ResponseEntity<ApiResponse<Object>> getLowStock() {
        return ResponseEntity.ok(ApiResponse.ok(productService.findLowStock()));
    }

    // GET /api/products/dashboard/summary
    @GetMapping("/dashboard/summary")
    public ResponseEntity<ApiResponse<Object>> getDashboardSummary() {
        return ResponseEntity.ok(ApiResponse.ok(productService.getStockSummary()));
    }

    // GET /api/products/filter/product-lines
    @GetMapping("/filter/product-lines")
    public ResponseEntity<ApiResponse<List<String>>> getProductLines() {
        return ResponseEntity.ok(ApiResponse.ok(productService.getProductLines()));
    }

    // GET /api/products/filter/vendors
    @GetMapping("/filter/vendors")
    public ResponseEntity<ApiResponse<List<String>>> getVendors() {
        return ResponseEntity.ok(ApiResponse.ok(productService.getVendors()));
    }

    // POST /api/products
    @PostMapping
    public ResponseEntity<ApiResponse<Object>> create(@Valid @RequestBody ProductDTO dto) {
        return ResponseEntity.status(HttpStatus.CREATED)
                .body(ApiResponse.ok("Product created", productService.create(dto)));
    }

    // PUT /api/products/{productCode}
    @PutMapping("/{productCode}")
    public ResponseEntity<ApiResponse<Object>> update(
            @PathVariable String productCode,
            @Valid @RequestBody ProductDTO dto) {
        return ResponseEntity.ok(ApiResponse.ok("Product updated",
                productService.update(productCode, dto)));
    }

    // DELETE /api/products/{productCode}
    @DeleteMapping("/{productCode}")
    public ResponseEntity<ApiResponse<Object>> delete(@PathVariable String productCode) {
        productService.delete(productCode);
        return ResponseEntity.ok(ApiResponse.ok("Product deleted", null));
    }
}
```

> ⚠️ **方法順序陷阱**：`/low-stock`、`/dashboard/summary`、`/filter/*` 這些**固定路徑必須寫在 `/{productCode}` 之前**，否則會被當成 productCode。Spring 依宣告順序比對，也精確匹配固定路徑。

# 10. 例外處理與統一回傳

## 10.1 概念

當某層拋出例外（例如找不到產品），若沒處理，Spring 會回傳**不友善的 500 跟一堆堆疊**。我們用 `@RestControllerAdvice` **集中攔截**所有 Controller 例外，轉成**統一的 JSON 錯誤格式**。

| 業務規則違反 | 400 | `{ success:false, errorCode:"BAD_REQUEST", message:"..." }` |

```java
// src/main/java/com/classicmodels/inventory/exception/GlobalExceptionHandler.java
package com.classicmodels.inventory.exception;

import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.validation.FieldError;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

import java.util.HashMap;
import java.util.Map;

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(ResourceNotFoundException.class)
    public ResponseEntity<Map<String, Object>> handleNotFound(ResourceNotFoundException ex) {
        return buildError(HttpStatus.NOT_FOUND, "NOT_FOUND", ex.getMessage());
    }

    @ExceptionHandler(IllegalArgumentException.class)
    public ResponseEntity<Map<String, Object>> handleBadRequest(IllegalArgumentException ex) {
        return buildError(HttpStatus.BAD_REQUEST, "BAD_REQUEST", ex.getMessage());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<Map<String, Object>> handleValidation(MethodArgumentNotValidException ex) {
        Map<String, String> fieldErrors = new HashMap<>();
        for (FieldError fe : ex.getBindingResult().getFieldErrors()) {
            fieldErrors.put(fe.getField(), fe.getDefaultMessage());
        }
        Map<String, Object> body = new HashMap<>();
        body.put("success", false);
        body.put("errorCode", "VALIDATION_ERROR");
        body.put("errors", fieldErrors);
        return ResponseEntity.badRequest().body(body);
    }

    private ResponseEntity<Map<String, Object>> buildError(
            HttpStatus status, String errorCode, String message) {
        Map<String, Object> body = new HashMap<>();
        body.put("success", false);
        body.put("errorCode", errorCode);
        body.put("message", message);
        return ResponseEntity.status(status).body(body);
    }
}
```

# 11. CORS：解決跨域問題

## 11.1 概念

前端（port 4200/3000/5173）與後端（port 8080）**不同源**。瀏覽器會擋下跨源請求。**CORS** 是後端告訴瀏覽器「這些來源可以存取我」的機制。

我們要**允許三個前端來源**存取 `/api/**`。

## 11.2 動手做：CorsConfig

```java
// src/main/java/com/classicmodels/inventory/config/CorsConfig.java
package com.classicmodels.inventory.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.web.cors.CorsConfiguration;
import org.springframework.web.cors.UrlBasedCorsConfigurationSource;
import org.springframework.web.filter.CorsFilter;

import java.util.List;

@Configuration
public class CorsConfig {

    @Bean
    public CorsFilter corsFilter() {
        CorsConfiguration config = new CorsConfiguration();
        config.setAllowedOrigins(List.of(
                "http://localhost:4200",   // Angular
                "http://localhost:3000",   // React CRA
                "http://localhost:5173"    // Vite
        ));
        config.setAllowedMethods(List.of("GET", "POST", "PUT", "DELETE", "OPTIONS"));
        config.setAllowedHeaders(List.of("*"));

        UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
        source.registerCorsConfiguration("/api/**", config);
        return new CorsFilter(source);
    }
}
```

### 為什麼要 `OPTIONS`？

前置請求（Preflight）用 OPTIONS——瀏覽器在真正送出有客製 header / 非簡單方法的請求前，會先打 OPTIONS 問「允許嗎」。沒有它，POST/PUT 會被擋。

## 12.5 ProductService（HttpClient + RxJS）

```typescript
// src/app/services/product.service.ts
import { Injectable } from '@angular/core';
import { HttpClient, HttpParams } from '@angular/common/http';
import { Observable, map } from 'rxjs';
import { Product, ApiResponse } from '../models/product.model';
import { StockSummary, StockThreshold } from '../models/stock-summary.model';

@Injectable({ providedIn: 'root' })
export class ProductService {

  private readonly apiUrl = 'http://localhost:8080/api';

  constructor(private http: HttpClient) {}

  // ── 產品 CRUD ─────────────────────────────
  getProducts(filters?: {
    productLine?: string; vendor?: string; keyword?: string;
  }): Observable<Product[]> {
    let params = new HttpParams();
    if (filters?.productLine) params = params.set('productLine', filters.productLine);
    if (filters?.vendor)      params = params.set('vendor', filters.vendor);
    if (filters?.keyword)     params = params.set('keyword', filters.keyword);
    return this.http.get<ApiResponse<Product[]>>(`${this.apiUrl}/products`, { params })
               .pipe(map(res => res.data));
  }

  getProductById(productCode: string): Observable<Product> {
    return this.http.get<ApiResponse<Product>>(`${this.apiUrl}/products/${productCode}`)
               .pipe(map(res => res.data));
  }

  createProduct(product: Product): Observable<Product> {
    return this.http.post<ApiResponse<Product>>(`${this.apiUrl}/products`, product)
               .pipe(map(res => res.data));
  }

  updateProduct(productCode: string, product: Product): Observable<Product> {
    return this.http.put<ApiResponse<Product>>(
      `${this.apiUrl}/products/${productCode}`, product)
               .pipe(map(res => res.data));
  }

  deleteProduct(productCode: string): Observable<void> {
    return this.http.delete<void>(`${this.apiUrl}/products/${productCode}`);
  }

  // ── 庫存監控 ─────────────────────────────
  getLowStockProducts(): Observable<Product[]> {
    return this.http.get<ApiResponse<Product[]>>(`${this.apiUrl}/products/low-stock`)
               .pipe(map(res => res.data));
  }

  getDashboardSummary(): Observable<StockSummary[]> {
    return this.http.get<ApiResponse<StockSummary[]>>(
      `${this.apiUrl}/products/dashboard/summary`)
               .pipe(map(res => res.data));
  }

  getProductLines(): Observable<string[]> {
    return this.http.get<ApiResponse<string[]>>(
      `${this.apiUrl}/products/filter/product-lines`)
               .pipe(map(res => res.data));
  }

  getVendors(): Observable<string[]> {
    return this.http.get<ApiResponse<string[]>>(
      `${this.apiUrl}/products/filter/vendors`)
               .pipe(map(res => res.data));
  }

  getThreshold(productCode: string): Observable<StockThreshold> {
    return this.http.get<ApiResponse<StockThreshold>>(
      `${this.apiUrl}/thresholds/${productCode}`)
               .pipe(map(res => res.data));
  }

  saveThreshold(productCode: string, minQuantity: number, reorderQuantity: number)
    : Observable<StockThreshold> {
    return this.http.put<ApiResponse<StockThreshold>>(
      `${this.apiUrl}/thresholds/${productCode}`,
      { minQuantity, reorderQuantity })
               .pipe(map(res => res.data));
  }
}
```

### 概念：為什麼用 `map(res => res.data)`？

後端回傳 `{ success, message, data }`。我們只想要裡面的 `data`，所以在 Service 就先「解開」。

### 概念：RxJS subscribe

`getDashboardSummary()` 傳回 **Observable（流）**。`.subscribe(callback)` 就像「訂閱」：資料一來就執行 callback。單筆請求可用簡單 subscribe；多請求並行可用 `forkJoin` 或 `Promise.all` 對應的 RxJS 寫法。

```typescript
  editingCode = '';
  editMinQty = 200;
  editReorderQty = 500;

  constructor(private productService: ProductService) {}

  ngOnInit(): void { this.loadLowStock(); }

  loadLowStock(): void {
    this.productService.getLowStockProducts().subscribe(products => {
      this.lowStock = products;
      products.forEach(p => {
        this.productService.getThreshold(p.productCode).subscribe({
          next: t => this.thresholdMap[p.productCode] = t,
          error: () => {}   // 沒有就維持預設
        });
      });
    });
  }

  startEdit(p: Product): void {
    this.editingCode = p.productCode;
    this.editMinQty     = this.thresholdMap[p.productCode]?.minQuantity ?? 200;
    this.editReorderQty = this.thresholdMap[p.productCode]?.reorderQuantity ?? 500;
  }

  save(code: string): void {
    this.productService.saveThreshold(code, this.editMinQty, this.editReorderQty)
        .subscribe(t => {
          this.thresholdMap[code] = t;
          this.cancel();
        });
  }

  cancel(): void { this.editingCode = ''; }
}
```

```typescript
// src/services/productService.ts
import axios from 'axios';
import { Product, ApiResponse } from '../models/product';
import { StockSummary, StockThreshold } from '../models/stock-summary';

const API_URL = 'http://localhost:8080/api';

const api = axios.create({ baseURL: API_URL });

// 從 ApiResponse<T> 只解出 data
async function unwrap<T>(promise: Promise<{ data: ApiResponse<T> }>): Promise<T> {
  const res = await promise;
  return res.data.data;
}

export async function getProducts(filters?: {
  productLine?: string; vendor?: string; keyword?: string;
}): Promise<Product[]> {
  const params: Record<string, string> = {};
  if (filters?.productLine) params.productLine = filters.productLine;
  if (filters?.vendor)      params.vendor = filters.vendor;
  if (filters?.keyword)     params.keyword = filters.keyword;
  return unwrap<Product[]>(api.get('/products', { params }));
}

export async function getProductById(productCode: string): Promise<Product> {
  return unwrap<Product>(api.get(`/products/${productCode}`));
}

export async function createProduct(product: Product): Promise<Product> {
  return unwrap<Product>(api.post('/products', product));
}

export async function updateProduct(productCode: string, product: Product): Promise<Product> {
  return unwrap<Product>(api.put(`/products/${productCode}`, product));
}

export async function deleteProduct(productCode: string): Promise<void> {
  await api.delete(`/products/${productCode}`);
}

export async function getLowStockProducts(): Promise<Product[]> {
  return unwrap<Product[]>(api.get('/products/low-stock'));
}

export async function getDashboardSummary(): Promise<StockSummary[]> {
  return unwrap<StockSummary[]>(api.get('/products/dashboard/summary'));
}

export async function getProductLines(): Promise<string[]> {
  return unwrap<string[]>(api.get('/products/filter/product-lines'));
}

export async function getVendors(): Promise<string[]> {
  return unwrap<string[]>(api.get('/products/filter/vendors'));
}

export async function getThreshold(productCode: string): Promise<StockThreshold> {
  return unwrap<StockThreshold>(api.get(`/thresholds/${productCode}`));
}

export async function saveThreshold(
  productCode: string,
  minQuantity: number,
  reorderQuantity: number
): Promise<StockThreshold> {
  return unwrap<StockThreshold>(
    api.put(`/thresholds/${productCode}`, { minQuantity, reorderQuantity })
  );
}
```

```tsx
// src/pages/ProductList.tsx
import { useEffect, useState } from 'react';
import {
  getProducts, getProductLines, getVendors
} from '../services/productService';
import { Product } from '../models/product';

function ProductList() {
  const [products, setProducts] = useState<Product[]>([]);
  const [productLines, setProductLines] = useState<string[]>([]);
  const [vendors, setVendors] = useState<string[]>([]);
  const [keyword, setKeyword] = useState('');
  const [selectedLine, setSelectedLine] = useState('');
  const [selectedVendor, setSelectedVendor] = useState('');

  useEffect(() => {
    loadProducts();
    getProductLines().then(setProductLines);
    getVendors().then(setVendors);
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, []);

  function loadProducts() {
    getProducts({
      productLine: selectedLine || undefined,
      vendor:      selectedVendor || undefined,
      keyword:     keyword || undefined
    }).then(setProducts);
  }

  function reset() {
    setKeyword(''); setSelectedLine(''); setSelectedVendor('');
  }
```

```js
// src/api/productService.js
import axios from 'axios';

const api = axios.create({ baseURL: '' });   // 用 Vite proxy，不用寫網址

async function unwrap(promise) {
  const res = await promise;
  return res.data.data;                       // 解開 { success, message, data }
}

export async function getProducts(filters = {}) {
  const params = {};
  if (filters.productLine) params.productLine = filters.productLine;
  if (filters.vendor)      params.vendor = filters.vendor;
  if (filters.keyword)     params.keyword = filters.keyword;
  return unwrap(api.get('/api/products', { params }));
}

export async function getProductById(id) {
  return unwrap(api.get(`/api/products/${id}`));
}

export async function getLowStockProducts() {
  return unwrap(api.get('/api/products/low-stock'));
}

export async function getDashboardSummary() {
  return unwrap(api.get('/api/products/dashboard/summary'));
}

export async function getProductLines() {
  return unwrap(api.get('/api/products/filter/product-lines'));
}

export async function getVendors() {
  return unwrap(api.get('/api/products/filter/vendors'));
}

export async function getThreshold(code) {
  return unwrap(api.get(`/api/thresholds/${code}`));
}

export async function saveThreshold(code, minQuantity, reorderQuantity) {
  return unwrap(api.put(`/api/thresholds/${code}`, { minQuantity, reorderQuantity }));
}
```

> 💡 **比較**：Vite 版用 `/api/...`（走 proxy），Angular/React 版用 `http://localhost:8080/api`（走 CORS）。兩種方案都可行，工作是等價的。

## 15.4 常見問題排解

| 徵狀 | 原因 | 解法 |
|------|------|------|
| 前端請求被 CORS 擋 | 後端沒開 5173 | CorsConfig 加上該 port |
| 連不上 MySQL | 帳密/連線字串錯 | 檢查 application.properties |
| `ddl-auto=update` 更新不到 | 表已存在但欄位不同 | 手動 ALTER 或移民工具 |
| 中文字變亂碼 | 沒加 `characterEncoding=UTF-8` | 檢查連線字串與資料庫 charset |

## 練習 3：庫存狀態查詢參數（難度：★★）

**目標**：Dashboard 的「低庫存警示」也想支援 `lowStockOnly` 與產品線合併篩選。

**提示**：

```java
// 方法命名 + @Query 合併條件
```

**驗證**：指定產品線後，清單只顯示該線的低庫存產品。

## 練習 4：批次更新安全水位（難度：★★★）

**目標**：一次送出多筆水位設定（PUT `/api/thresholds/batch`），全部成功或全部失敗（交易）。

**提示**：用 `@Transactional` 包住迴圈 upsert；InputBody 用 `List<Map<String,Object>>` 承接。

```java
@PutMapping("/batch")
@Transactional
public ResponseEntity<ApiResponse<Object>> batchUpsert(
        @RequestBody List<Map<String, Object>> items) {
    for (Map<String, Object> item : items) {
        thresholdService.upsert(
            (String) item.get("productCode"),
            (int) item.get("minQuantity"),
            (int) item.get("reorderQuantity"));
    }
    return ResponseEntity.ok(ApiResponse.ok("Batch saved", null));
}
```

> ⚠️ 若其中一筆失敗，`@Transactional` 會**全部回滾**——這就是交易的好處。

**驗證**：送 3 筆，其中一筆是 `NOT_EXIST`，確認前 2 筆也**沒被寫入**。

## 練習 5：儀表板加入總庫存價值（難度：★★★）

**目標**：Dashboard 顯示「總庫存價值 = Σ (quantityInStock × buyPrice)」。

**提示**：新增一組 JPQL：
```java
@Query("SELECT COALESCE(SUM(p.quantityInStock * p.buyPrice), 0) FROM Product p")
double getTotalInventoryValue();
```
在 Service 組合 `StockSummaryDTO` 一起回傳。

**驗證**：卡片多一格「總庫存價值」，數字與手算一致。
