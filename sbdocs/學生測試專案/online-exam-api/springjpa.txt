1. 在Spring中如何將一個類標註為Bean並讓Spring管理？
    @_____
    public class A {
        // class body
    }

    - a) `@Component`
    - b) `@Service`
    - c) `@Repository`
    - d) 以上皆是  
    

2. 如何定義一個攔截所有請求的控制器？
   
@_____
    public class GlobalController {
        @RequestMapping("/*")
        public String handleAll() {
            return "global";
        }
    }
    ```
    - a) `@Controller`
    - b) `@GetMapping `
    - c) `@Component`
    - d) `@Service`  
  
 
3. 如何定義一個方法來接收查詢參數？
    
    @RestController
    public class MyController {

            return "Hello " + name;
        }
    }
    ```
    - a) `@Param `
    - b) `@PathVariable`
    - c) `@QueryParam`
    - d) `@ RequestParam`

6. 如何在JPA中宣告資料庫欄位`@ManyToOne`註解？
    
    @Entity
    public class Order {
        @Id
        @GeneratedValue(strategy = GenerationType.IDENTITY)
        private Long id;
        @ManyToOne
        @_____(name = "user_id")
        private User user;
    }
    ```
    - a) `@JoinTable`
    - b) `@JoinColumn`
    - c) `@Column`
    - d) `@Embedded`  
    
 

˙7.如何在JPA中使用`@Query`註解進行自訂查詢？
    ```
