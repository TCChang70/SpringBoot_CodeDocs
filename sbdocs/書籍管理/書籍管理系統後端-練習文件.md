# 1. 系統情境與需求

## 1.1 業務背景

一間圖書館推出**線上書籍管理系統**。館員維護書目、讀者查詢與借閱書籍。

- 每本書有**分類**（小說 / 科技 / 歷史 / 語言 / 其他）。
- 每本書有**總冊數**與**目前可借冊數**（available_copies）。
- 讀者借書時，系統要：**扣可借冊數 + 建立借閱記錄**，整個流程必須是**同一交易**。
- 歸還時：**補回可借冊數 + 更新借閱記錄**，同樣要在**同一交易**完成。
- 館員需要**儀表板**：熱門借閱排行、逾期未還筆數、今日借出數量。

## 1.2 需求規格表

| 編號 | 功能 | 說明 | 層 |
|------|------|------|-----|
| FR-01-01 | 書籍 CRUD | 新增/查詢/編輯/刪除書目 | Service/Controller |
| FR-01-02 | 書籍篩選 | 依分類、是否有庫存查詢 | Repository |
| FR-01-03 | 關鍵字搜尋 | 依書名或作者模糊搜尋（不分大小寫） | Repository |
| FR-02-01 | 借閱書籍 | 扣可借冊數 + 建借閱記錄（同一交易） | Service |
| FR-02-02 | 歸還書籍 | 補回可借冊數 + 更新記錄（同一交易） | Service |
| FR-02-03 | 借閱查詢 | 依狀態（ACTIVE/RETURNED/OVERDUE）篩選 | Repository |
| FR-03-01 | 儀表板統計 | 熱門借閱排行、逾期筆數、今日借出數 | Repository |
| FR-03-02 | 逾期清單 | 列出超過歸還日且未歸還的借閱記錄 | Repository |

## 1.3 ER 圖（關聯已設計好）

```
books（書籍）
   id              BIGINT       PK AUTO_INCREMENT
   title           VARCHAR(200) NOT NULL
   author          VARCHAR(100) NOT NULL
   isbn            VARCHAR(20)  NOT NULL UNIQUE
   category        VARCHAR(50)  NOT NULL
   publisher       VARCHAR(100)
   publish_year    YEAR
   total_copies    INT          NOT NULL DEFAULT 1
   available_copies INT         NOT NULL DEFAULT 1
   description     TEXT

loans（借閱記錄）
   id             BIGINT     PK AUTO_INCREMENT
   book_id        BIGINT     FK → books.id
   borrower_name  VARCHAR(50) NOT NULL
   borrow_date    DATE        NOT NULL
   due_date       DATE        NOT NULL
   return_date    DATE        NULL        -- NULL = 尚未歸還
   status         VARCHAR(20) NOT NULL DEFAULT 'ACTIVE'
                              -- ACTIVE / RETURNED / OVERDUE
```

關聯：`books 1 ── N loans`（一本書可被多次借閱）

> 💡 **設計重點**：
> - `available_copies` 可能小於 `total_copies`（有書在外面沒還）。
> - `return_date` 設 NULL 表示「尚未歸還」，避免用一個魔法數字。
> - `status` 有三個值：ACTIVE（借中）、RETURNED（已還）、OVERDUE（逾期）。

## 7.1 BookService（CRUD）

```java
// src/main/java/com/example/library/service/BookService.java
package com.example.library.service;

import com.example.library.dto.BookRequest;
import com.example.library.exception.ResourceNotFoundException;
import com.example.library.exception.DuplicateIsbnException;
import com.example.library.model.Book;
import com.example.library.repository.BookRepository;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.List;

@Service
public class BookService {

    private final BookRepository bookRepo;

    public BookService(BookRepository bookRepo) {
        this.bookRepo = bookRepo;
    }

    @Transactional(readOnly = true)
    public List<Book> findAll() { return bookRepo.findAll(); }

    @Transactional(readOnly = true)
    public List<Book> findByCategory(String category) { return bookRepo.findByCategory(category); }

    @Transactional(readOnly = true)
    public List<Book> findAvailable() {
        return bookRepo.findByAvailableCopiesGreaterThan(0);
    }

    @Transactional(readOnly = true)
    public List<Book> search(String keyword) { return bookRepo.searchByKeyword(keyword); }

    @Transactional(readOnly = true)
    public Book findById(Long id) {
        return bookRepo.findById(id)
                .orElseThrow(() -> new ResourceNotFoundException("Book not found: " + id));
    }

    @Transactional
    public Book create(BookRequest req) {
        // [A] 檢查 ISBN 是否重複（若重複拋 DuplicateIsbnException）
        bookRepo.findByIsbn(req.getIsbn()).ifPresent(b -> {
            throw new [A]________("ISBN 已存在: " + req.getIsbn());
        });

        Book b = new Book();
        b.setTitle(req.getTitle());
        b.setAuthor(req.getAuthor());
        b.setIsbn(req.getIsbn());
        b.setCategory(req.getCategory());
        b.setPublisher(req.getPublisher());
        b.setPublishYear(req.getPublishYear());
        b.setTotalCopies(req.getTotalCopies());
        b.setAvailableCopies(req.getTotalCopies());  // 新書：可借冊數 = 總冊數
        b.setDescription(req.getDescription());
        return bookRepo.save(b);
    }

    @Transactional
    public Book update(Long id, BookRequest req) {
        Book b = findById(id);
        // 若 ISBN 改變，需檢查新 ISBN 是否與其他書重複
        if (!b.getIsbn().equals(req.getIsbn())) {
            bookRepo.findByIsbn(req.getIsbn()).ifPresent(other -> {
                throw new DuplicateIsbnException("ISBN 已存在: " + req.getIsbn());
            });
        }
        b.setTitle(req.getTitle());
        b.setAuthor(req.getAuthor());
        b.setIsbn(req.getIsbn());
        b.setCategory(req.getCategory());
        b.setPublisher(req.getPublisher());
        b.setPublishYear(req.getPublishYear());
        b.setDescription(req.getDescription());
```

```java
// src/main/java/com/example/library/exception/GlobalExceptionHandler.java
package com.example.library.exception;

import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.validation.FieldError;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

import java.util.HashMap;
import java.util.Map;

@RestControllerAdvice
public class GlobalExceptionHandler {

    // 404
    @ExceptionHandler(ResourceNotFoundException.class)
    public ResponseEntity<Map<String, Object>> handleNotFound(ResourceNotFoundException ex) {
        return buildError(HttpStatus.NOT_FOUND, "NOT_FOUND", ex.getMessage());
    }

    // 400：書籍無可借冊數
    @ExceptionHandler(BookNotAvailableException.class)
    public ResponseEntity<Map<String, Object>> handleNotAvailable(BookNotAvailableException ex) {
        return buildError(HttpStatus.BAD_REQUEST, "BOOK_NOT_AVAILABLE", ex.getMessage());
    }

    // 409：ISBN 重複
    @ExceptionHandler(DuplicateIsbnException.class)
    public ResponseEntity<Map<String, Object>> handleDuplicate(DuplicateIsbnException ex) {
        return buildError(HttpStatus.CONFLICT, "DUPLICATE_ISBN", ex.getMessage());
    }

    // 400：業務狀態錯誤（如重複歸還）
    @ExceptionHandler(IllegalStateException.class)
    public ResponseEntity<Map<String, Object>> handleState(IllegalStateException ex) {
        return buildError(HttpStatus.BAD_REQUEST, "INVALID_STATE", ex.getMessage());
    }

    // 400：Validation
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<Map<String, Object>> handleValidation(MethodArgumentNotValidException ex) {
        Map<String, String> fieldErrors = new HashMap<>();
        ex.getBindingResult().getFieldErrors()
          .forEach(fe -> fieldErrors.put(fe.getField(), fe.getDefaultMessage()));
        Map<String, Object> body = new HashMap<>();
        body.put("success", false);
        body.put("errorCode", "VALIDATION_ERROR");
        body.put("errors", fieldErrors);
        return ResponseEntity.badRequest().body(body);
    }

    private ResponseEntity<Map<String, Object>> buildError(
            HttpStatus status, String errorCode, String message) {
        Map<String, Object> body = new HashMap<>();
        body.put("success", false);
        body.put("errorCode", errorCode);
        body.put("message", message);
        return ResponseEntity.status(status).body(body);
    }
}
```
