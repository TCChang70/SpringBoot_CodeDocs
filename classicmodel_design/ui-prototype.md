## 2. 設計規範

### 2.1 整體版面（Layout）

```
┌──────────────────────────────────────────────────────────────────┐
│ Header：Logo | 導覽選單 | 歡迎訊息 | 登出                        │
├────────────┬─────────────────────────────────────────────────────┤
│ Sidebar    │ 內容區 Content                                       │
│ 功能選單    │  麵包屑 / 頁面標題                                   │
│            │  篩選列 / 工具列 / 內容表格 / 表單                   │
│            │  分頁列                                               │
├────────────┴─────────────────────────────────────────────────────┤
│ Footer：版本 | 版權                                             │
└──────────────────────────────────────────────────────────────────┘
```

### 2.2 色彩與樣式

| 項目 | 規範 |
|------|------|
| 框架 | Bootstrap 5.3 |
| 主色 | 深藍 `#1E3A8A`（品牌）、輔助色 橘 `#F59E0B` |
| 狀態色 | 成功綠、警示黃、錯誤紅（Bootstrap 標準色） |
| 字體 | 系統預設字體；標題 18px、內文 14px |
| 響應式 | ≥1200px 三欄、768–1199px 兩欄、<768px 單欄堆疊 |

### 2.3 狀態顏色定義

| 狀態 | 顏色 | 用途 |
|------|------|------|
| In Process | 黃底黑字 Badge | 訂單處理中 |
| Shipped | 藍底白字 Badge | 已出貨 |
| Resolved | 綠底白字 Badge | 已完成 |
| Cancelled | 灰底白字 Badge | 已取消 |
| LOW（庫存不足） | 紅底白字 Badge | 庫存 < 20 |
| OVER_LIMIT（超額度） | 紅底白字 | 客戶超信用額度 |

### 2.4 共用元件

| 元件 | 說明 |
|------|------|
| DataTable | 統一列表元件：表頭排序、多欄篩選、分頁（每頁 20）、勾選列 |
| SearchBar | 關鍵字輸入 + 進階篩選（展開面板） |
| ConfirmDialog | 刪除/送出前二次確認 Modal |
| Toast | 右上角操作結果提示（成功/失敗） |
| Spinner | 資料載入中遮罩 |
| EmptyState | 無資料時顯示圖示與說明 |
| PageTitle | 頁面標題 + 主要動作按鈕（新增/匯出） |

## 11. 互動與流程規範

| 情境 | 行為 |
|------|------|
| 刪除被參照資料 | ConfirmDialog 提示「此資料已有交易記錄，無法刪除」並禁用刪除鍵 |
| 送出訂單前 | 顯示總金額確認 Modal；庫存不足在欄位旁即時紅字提示 |
| 出貨操作 | 顯示「將扣減庫存 N 件」確認訊息 |
| 操作成功 | 右上角 Toast「已儲存」；列表自動刷新 |
| 401 | 跳回登入頁並提示「登入已過期」 |
| 無權限 | 顯示「403 無權限」頁面 |
| 表單錯誤 | 欄位紅框 + 下方錯誤文字；送出時捲動到第一個錯誤欄位 |
| 資料載入中 | 內容區 Spinner；禁止重複點擊送出按鈕 |
